# 指标字典 · Metrics Dictionary

> 口径统一是数据分析的第一道工序。本文档沉淀项目全部指标：名称 / 公式 / 维度 / 口径 / 示例值。
> 所有示例值均来自本项目抽样后真实计算结果（5% 用户抽样，seed=42，本地时区 Europe/Moscow UTC+3）。

## 0. 全局口径

| 口径项 | 定义 |
|---|---|
| **抽样口径** | 按 **user_id** 抽样（`user_id % 100 < 5` ≈ 5% 用户），非按行抽样——保证每个用户的事件序列完整，漏斗/留存/RFM 不失真 |
| **时区口径** | 原始 `event_time` 为 UTC，入库前统一转 **Europe/Moscow（UTC+3）**；分时分布以此为准（浏览高峰 19 点、购买高峰 12 点） |
| **日期口径** | `event_date` 取本地时区日期；数据窗口 2019-11-01 → 2019-12-01（UTC→+3 溢出 1 天） |
| **价格口径** | `price_valid = price > 0 且非空`；异常价标记而非删除（占比 0.27%） |
| **购买口径** | 购买事件 = `event_type = 'purchase'` 且 `price_valid`；本数据集无 `remove_from_cart` |
| **用户层级** | 「用户数」= `DISTINCT user_id`；「购买用户」= 有过 purchase 事件的用户 |
| **会话层级** | `user_session` 缺失以 `NO_SESSION_<index>` 兜底（占比见数据质量报告） |

## 5. 用户价值（RFM）

| # | 指标 | 公式 | 维度 | 示例值 |
|---|---|---|---|---|
| 22 | **R（最近购买）** | `窗口末 − 最近购买日`（天，越小越好） | 用户 | 中位 0 |
| 23 | **F（购买频次）** | `COUNT(purchase)` | 用户 | 中位 2 |
| 24 | **M（累计消费）** | `SUM(price)` | 用户 | 均值 606 |
| 25 | **RFM 评分** | 五分位打分 1–5（R 反向），均值二分（≥3=高）→ 8 组 | 用户 | 见下表 |
| 26 | **各组人数占比 / GMV 占比** | `segment 人数/总购买用户`、`segment GMV/总 GMV` | segment | 重要价值客户 28.9% 人 / 60.0% GMV |

## 6. 专题与归因

| # | 指标 | 公式 | 维度 | 示例值 |
|---|---|---|---|---|
| 27 | **新客 GMV 占比** | `首单用户 GMV / 总 GMV` | 期间 | 大促期 74.0% vs 平日 60.6% |
| 28 | **品类 GMV 占比** | `品类 GMV / 总 GMV`（顶层品类） | 品类 | electronics 居首 |
| 29 | **环比（WoW）** | `(本周 − 上周) / 上周` | 周/品类 | 见 SQL 题 8 |
| 30 | **GMV 量价拆解贡献** | `ΔGMV = 人数贡献 + 频次贡献 + 均价贡献`（一阶差分） | 期间 | 人数 +84% / 频次 +10% / 均价 +6% |
| 31 | **GMV 构成拆解贡献** | 各品类/新老客/价格带的 GMV 增量 | 品类/新老客 | electronics +1,034,878/日 |

## 附：GMV 拆解树（OSM）

```
                    GMV（North Star）
        ┌───────────────┼────────────────┐
    购买用户数         人均订单          客单价
    (转化率×UV)      (复购频次)       (价格策略)
        │               │
     流量漏斗          留存/复购         品类结构
   view→cart→purchase  D1/D7留存        新老客占比
```

「量价拆解」即沿此树做一阶差分：`ΔGMV = Δ购买用户数 × f̄ × ā + ū × Δf × ā + ū × f̄ × Δā`。
