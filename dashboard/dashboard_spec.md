# 看板五模块布局说明 · Dashboard Spec

> 目标：把 8 张分析图 + 核心指标卡组装成一块可演示的经营看板，对应 FineBI / Tableau 五模块。
> 图表已由 `src/viz.py` 统一配色导出至 `dashboard/figures/`（浅色表面 #fcfcfb，分类 8 色 + 蓝系顺序色）。

## 整体布局（自上而下）

```
┌──────────────────────────────────────────────────────────────┐
│ ① 核心指标卡（4 张，带环比箭头）                               │
├──────────────┬───────────────────────┬───────────────────────┤
│ ② 流量与漏斗  │ ③ 留存热力           │ ④ 用户价值            │
├──────────────┴───────────────────────┴───────────────────────┤
│ ⑤ 专题页（黑五对比 + 异动归因下钻）                            │
└──────────────────────────────────────────────────────────────┘
```

---

## ① 核心指标卡（KPI 卡）

| 指标 | 当前值 | 环比（平日基准） | 数据来源 |
|---|---:|---:|---|
| **月 GMV** | ¥13,254,562 | —（单月） | `daily_metrics.gmv.sum()` |
| **日均 UV** | 13,793 | 峰值 11-16 达 24,329 | `daily_metrics.uv` |
| **整体转化率** | 11.91% | 黑五当日 7.95% | `购买用户/UV` |
| **客单价 AOV** | ¥292.67 | 黑五当日 ¥317.51 | `GMV/订单数` |

> 说明：环比箭头在 FineBI 中配置为「与上月/上周基准对比」，本项目为单月数据，此处环比改为「大促/黑五 vs 平日」。

## 导出与复现

- **FineBI 个人版**（免费）：按上表将 `dashboard/figures/*.png` 拖入仪表盘，或直连 `data/ecommerce.db` 实时取数。
- **Tableau Public**（免费公开链接，可挂简历）：连接 `data/processed/*.parquet` 或 `data/ecommerce.db`。
- 两版做一即可；本项目的图已可独立成页。
