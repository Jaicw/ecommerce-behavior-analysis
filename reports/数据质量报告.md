# 数据质量报告（D4 出关）

> 数据集：Kaggle 多品类电商 2019-11 单月（抽样后 5% 用户全量事件）。

## 1. 规模

| 项目 | 值 |
|---|---|
| 原始抽样行数 | 3,335,944 |
| 清洗后行数 | 3,331,496 |
| 删除完全重复行 | 4,448 |
| 去重用户数 | 183,592 |
| 去重商品数 | 116,684 |

## 2. 字段缺失率

| 字段 | 缺失数 | 缺失率 | 处理策略 |
|---|---|---|---|
| event_time | 0 | 0 (0.00%) | 保留原值 |
| event_type | 0 | 0 (0.00%) | 保留原值 |
| product_id | 0 | 0 (0.00%) | 保留原值 |
| category_id | 0 | 0 (0.00%) | 保留原值 |
| category_code | 1,083,368 | 1,083,368 (32.48%) | 填充为 unknown（保留） |
| brand | 453,193 | 453,193 (13.59%) | 保留原值（分析按 unknown 归并） |
| price | 0 | 0 (0.00%) | 标记 price_invalid，GMV 不计入 |
| user_id | 0 | 0 (0.00%) | 无法归属，剔除该行 |

## 3. 异常值处理规则

| 异常 | 规则 | 策略 |
|---|---|---|
| price <= 0 | 8,838 行 | 标记 `price_invalid`，不删除；GMV 仅统计有效价格 |
| price 为 NaN | 0 行 | 同上标记，不删除 |
| user_session 缺失 | 2 行 | 补独立单事件会话 |
| category_code 缺失 | 1,082,173 行 | 归 unknown |

## 4. 时间覆盖完整性

- 时间下界：2019-11-01 03:00:00
- 时间上界：2019-12-01 02:59:58
- 覆盖天数：30 天
- 每日均有事件的天数：31 天

**时区口径**：原始 event_time 为 UTC，已统一转 Asia/Shanghai（UTC+8）本地时区，分时分布按此口径。

## 5. 分析表

| 表 | 行数 | 说明 |
|---|---|---|
| events | 3,331,496 | 全量清洗后事件 |
| orders | 45,289 | 购买事件（=订单行） |

## 6. 事件类型与数据说明

| 事件类型 | 行数 | 占比 |
|---|---|---|
| view | 3,140,509 | 94.27% |
| cart | 145,698 | 4.37% |
| purchase | 45,289 | 1.36% |

> **remove_from_cart 缺失**：2019-11 原始数据（含全量）不含 remove_from_cart 事件，仅 view / cart / purchase 三类。购物车放弃分析改用「加购但未购买」口径（cart → purchase 的流失）。
> **时区溢出**：原始 event_time 为 UTC，转 Asia/Shanghai(UTC+8) 后，11-30 晚间（UTC 16:00 后）事件落入 12-01 本地日，导致本地日期跨 31 天、首尾两天为不完整日。分时分析用本地时区，日粒度含 12-01 少量溢出（约 2.4 万行，占 0.7%）。
